# exp106: первичные данные эксперимента по контролю допуска Kubernetes

Архив содержит первичные данные к курсовой работе и статье Ереминой Е. А. и Простовой А. Н.
(РГУ нефти и газа (НИУ) имени И. М. Губкина, 2026) «Методика проверки полноты контроля
допуска Kubernetes на примере ограничения реестров контейнерных образов».

Стенд: две ВМ Альт Рабочая станция 11.1, K3s v1.36.5, OPA Gatekeeper v3.23.1,
ValidatingAdmissionPolicy, Pod Security Admission.

## Состав архива (85 файлов)

- `baseline/` – версии ПО, перечни пакетов, параметры ВМ и узлов;
- `manifests/` – тестовые поды t1–t6, политики Gatekeeper (собственная и библиотечная), VAP, Deployment;
- `results/` – результаты 162 попыток допуска (results.csv), протоколы PSS, временных контейнеров,
  Deployment, отказа контроллера и аудита, контрольные суммы манифестов (sha256sums.txt);
- `results/additional/` – дополнительный эксперимент 15.11.2026: задержка допуска,
  отказ контроллера при широкой (W1) и ограниченной (W2) области webhook, журнал прогона;
- `logs/` – журналы установки K3s;
- `exp_additional_checked.sh` – скрипт дополнительного эксперимента.

Ключи, токены и учетные данные из архива удалены.

Программа статической проверки: admission_check.py (версия 2) проверяет требования R1–R6 по сохраненным конфигурациям из архива и для каждого нарушения выводит причину, минимальный контрпример и требуемое изменение конфигурации. Запуск: python3 admission_check.py <путь к распакованному архиву>. Полный вывод для конфигураций K1–K6, M0–M8 и X1–X4 — в admission_check_output.txt.
